# Bleak Plan 06 — Audio

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sound that tells the player where the danger is, sells the storm-night setting, and never cuts out, stacks up or lags.

**Architecture:** All sound is client-side and uses the Audio API (AudioPlayer → AudioEmitter or bus → AudioDeviceOutput, joined by Wire). The server sends `Cue` events and replicated attributes; `AudioController` turns them into sound. Acoustic Simulation adds occlusion and reverb but no gameplay rule depends on it.

**Tech Stack:** Audio API, Acoustic Simulation, SoundService, Creator Store audio.

**Spec:** `docs/spec/2026-11-13-bleak-game-design.md` sections 10.4, 16, 17.

Agent: **Audio**. Every task uses the standard task cycle (master plan
section 7). Listening checks need the Studio token and a human ear: where a
step says "ask the user to listen", give them the exact thing to listen for
and a yes/no question.

### Task A1: Audio graph core

**Files:**
- Create: `src/client/Controllers/AudioController.luau`, `src/client/Audio/Graph.luau`, `src/client/Audio/Pool.luau`
- Create: `src/shared/Logic/AudioMath.luau`
- Test: `src/tests/unit/AudioMath.spec.luau`

**Interfaces — Produces:**

```lua
Graph.init()                                   -- builds buses once
Graph.bus(name: "Master" | "Sfx" | "Foley" | "Creature" | "Ambience" | "Music" | "Ui"): AudioFader
Graph.setVolume(name: string, linear: number)   -- 0..1, from settings
Pool.play3d(assetId: string, at: Vector3 | Instance, opts: { bus: string, volume: number?,
  rate: number?, distance: {min: number, max: number}?, loop: boolean? }): Handle
Pool.play2d(assetId: string, opts: { bus: string, volume: number?, rate: number?, loop: boolean? }): Handle
-- Handle: { stop: (fade: number?) -> (), setVolume: (v: number, fade: number?) -> () }
AudioMath.dbToLinear(db: number): number
AudioMath.pitchVariation(random: number, spread: number): number    -- 1 ± spread
AudioMath.shouldSteal(active: number, cap: number): boolean
```

**Behaviour:**
- Graph: `AudioListener` on the camera → bus faders → `Master` fader → `AudioDeviceOutput`. 2D sounds wire straight to a bus. 3D sounds: `AudioPlayer` → `AudioEmitter` (parented to an attachment at the position) → heard by the listener → bus by `AudioInteractionGroup`.
- Pool: 32 3D voices and 16 2D voices, pre-created. When all are busy, steal the quietest non-looping voice. Never create instances during play.
- Assets are preloaded with `ContentProvider:PreloadAsync` during the lobby.
- A sound whose asset fails to load is skipped with one warning, never an error.

**Tests:** `dbToLinear(0) == 1`; `dbToLinear(-6)` ≈ 0.501; `pitchVariation(0.5, 0.1) == 1`; `pitchVariation(0, 0.1) == 0.9`; `shouldSteal(32, 32)` true; `(31, 32)` false.

- [ ] Commit: `feat: add audio graph and voice pool`.

### Task A3: Cue system

**Files:** Modify `AudioController.luau`. Create `src/client/Audio/Cues.luau`.

```lua
Cues.play(cueId: string, at: (Vector3 | Instance)?): Handle?     -- nil position = 2D
Cues.loopOn(key: string, cueId: string, at: (Vector3 | Instance)?)   -- idempotent per key
Cues.loopOff(key: string, fade: number?)
```

**Behaviour:** listens to the `Cue` remote and calls `Cues.play`. Picks a random variation, never the same one twice in a row. Applies `pitchSpread`. The same cue id cannot start more than once per 0.05 s at the same position (within 2 studs). Unknown cue ids warn once.

### Task A4: Footsteps and player foley

**Files:** Create `src/client/Audio/Footsteps.luau`, `src/client/Audio/PlayerFoley.luau`. Create `src/shared/Logic/SurfaceMap.luau`. Test: `src/tests/unit/SurfaceMap.spec.luau`.

```lua
SurfaceMap.cueFor(material: Enum.Material, variantName: string?): string
```

**Behaviour:**
- For every player character (local and remote): a step sounds when the horizontal distance walked since the last step passes 4.2 studs (walk) or 5.2 (sprint). Crouched steps are 12 dB quieter. Downed players use `Crawl`.

- Step timing matches NoiseService's intervals closely enough that what players hear agrees with what the Keeper hears.
- Foley reads attributes: `LampOn`, `BeamOn`, `LampLocked`, `HeldItem`, `CandleLit`, `Stamina` (`Breath_Tired` loop below 25), `Status`.

### Task A5: Keeper audio

**Files:** Create `src/client/Audio/KeeperAudio.luau`.

| Keeper `State` | Sound |
|----------------|-------|
| `Dormant` | `Keeper_Radio_Loop` from the radio prop (static and a faint voice-like tone, no words) |
| `Roam` | `Keeper_Hum_Loop`, `Keeper_Step` on animation markers |
| `Investigate` | Hum stops. `Keeper_Breath_Loop` |
| `Chase` | `Keeper_Alert` once, then `Keeper_Chase_Loop` |
| `Enraged` | `Keeper_Scream` (from `KeeperEvent "Scream"`), then the chase loop 3 dB louder and 5% faster |
| `Carry` | `Keeper_Breath_Loop`, heavy steps |
| `Stunned` | `Keeper_Stunned` |
| `Calm` | `Keeper_Calm`, then silence except steps |

- All Keeper sounds are 3D from the Keeper's head or feet, distance 8–90.
- The scream is heard map-wide: distance 20–600, plus a 2D low layer at −12 dB so every player knows a release rage began.
- Local heartbeat: a 2D loop whose rate and volume rise as the Keeper gets nearer than 40 studs (rate 1.0 at 40 to 1.8 at 5). This is the main "it is close" signal and works without Acoustic Simulation.
- `Sting_Spotted` plays for the local player when their `Chased` attribute turns true (not more than once per 10 s).

### Task A7: Ambience, weather and acoustics

**Files:** Create `src/client/Audio/Ambience.luau`. Modify `tools/mapgen` only by asking Environment (acoustic properties are map data).

- Ambience beds follow the local `AmbienceZone` (using `ZoneMath`), cross-fading over 1.5 s. Outdoors: sea, wind, rain. Indoors: the zone's room tone plus `Amb_Rain_Roof_Loop` and muffled sea.
- 3D point sources placed by tag `AmbienceEmitter` (ask Environment to add ≥ 10: dripping pipes, a banging shutter, creaking beams, the buoy bell, waves at the Cove).
- Thunder follows VfxController's lightning event: `Thunder_Near` or `Thunder_Far`, delayed 0.3–2.5 s.
- Random `Creak` one-shots indoors every 20–60 s at a random point 15–30 studs away, never in line of sight. They are deliberately similar to Keeper steps to keep the player unsure; they never use the Keeper's exact step asset.
- Acoustic Simulation: set `SoundService.AcousticSimulationEnabled = true`. Ask Environment to set `AudioCanCollide = false` on small props and `AcousticAbsorption` on materials (wood 0.3, plaster 0.2, stone 0.05, metal 0.05, fabric 0.6).
- Fallback when simulation is off (low graphics): a manual indoor filter. If the local player and a 3D emitter are in different zones, lower it 6 dB and low-pass at 1,800 Hz with an `AudioFilter`. Detect by a setting flag and by comparing graphics level < 4.

**Checks:** ask the user to listen with simulation on and off: in both, a Keeper in the next room is audible, clearly quieter and duller than in the same room, and its direction is clear.

- [ ] Commit: `feat: add ambience, weather and acoustics`.

### Task A8: Adaptive music

**Files:** Create `src/client/Audio/Music.luau`, `src/shared/Logic/MusicRules.luau`. Test: `src/tests/unit/MusicRules.spec.luau`.

```lua
-- returns target linear volumes
MusicRules.layers(phase: MatchPhase, stage: number, chased: boolean, keeperState: KeeperState)
  : { lobby: number, low: number, mid: number, high: number, chase: number }
```

Rules: `Lobby` → lobby 1. `Dormant` → low 0.4. `Active` → low 1; mid 1 from
stage 4; high 1 from stage 7. `chased` → chase 1 and low, mid, high × 0.4.
`Enraged` (for anyone) → high 1 regardless of stage. `Won`, `Lost`,
`Results` → all 0 (stingers play instead).

- The three layers are the same length and tempo and start together in sync, looping; only volumes change. Fades 2.0 s; the chase layer fades in over 0.4 s and out over 3.0 s.
- `Sting_StageUp` on each release; `Sting_Win`, `Sting_Lose`, then `Mus_Win` or `Mus_Lose`.

**Tests:** `layers("Lobby", 0, false, "Dormant").lobby == 1` and the others 0; `("Active", 3, false, "Roam")` → low 1, mid 0, high 0; stage 4 → mid 1; stage 7 → high 1; `("Active", 2, true, "Chase")` → chase 1, low 0.4; `("Active", 1, false, "Enraged").high == 1`; `("Won", 9, true, "Chase")` → all 0.

### Task A9: Mix, settings and audio QA

**Files:** Modify `AudioController.luau`. Create `docs/audio/mix.md`.

- Mix targets: dialogue-free game, so creature sounds lead. Keeper scream is the loudest event. Ambience sits 12–18 dB under creature sounds. Music never masks footsteps: when the Keeper is within 30 studs and not chasing, music ducks 6 dB.
- Settings (from U10): Master, Music, Effects (Sfx + Foley + Creature), Ambience, UI sliders. Changes apply at once through `Graph.setVolume`.
- Menu open: low-pass the Master bus at 1,200 Hz.
- No sound continues after a match reset: on phase `Lobby`, stop every loop except lobby music and Dock ambience.
- Voice count: log the peak active voices in a 10-minute bot match. Expected ≤ 32 3D and ≤ 16 2D, zero steals of looping sounds.

**Checklist (with the user listening, results in `docs/audio/mix.md`):**
1. Can you tell which way the Keeper is, eyes closed, from 30 studs?
2. Can you tell roam from chase by sound alone?
3. Is any sound painfully loud at Master 100%?
4. Does any loop have an audible seam?
5. Does anything keep playing in the lobby after a match?
