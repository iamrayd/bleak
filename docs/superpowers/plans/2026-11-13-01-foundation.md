# Bleak Plan 01 — Foundation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A repository where every other workstream can write, test and merge code from the first day.

**Architecture:** Rojo maps `src/` into the place. Shared contracts (types, config, remotes) and stubs for every service exist before any real service. Unit tests run headlessly through Open Cloud and locally through Studio.

**Tech Stack:** Rokit, Rojo 7.7.1, Selene, StyLua, luau-lsp, Python 3, GitHub Actions, Studio MCP.

**Spec:** `docs/spec/2026-11-13-bleak-game-design.md`. Contracts: master plan sections 3, 5, 6.

Agent: **Foundation**. All tasks are sequential. Every task uses the standard
task cycle (master plan section 7). Until F3 is done there is no test runner;
F1 and F2 verify by the commands given.

### Task F3: TestKit and unit runner

**Files:**
- Create: `src/shared/Util/TestKit.luau`, `src/tests/RunUnit.luau`
- Create: `src/tests/unit/Signal.spec.luau`, `Rng.spec.luau`, `TableUtil.spec.luau`, `TestKit.spec.luau`

**Interfaces — Produces:**

A spec file is a ModuleScript whose name ends in `.spec` and which returns
`function(t)`.

```lua
t.describe(name: string, fn: () -> ())
t.it(name: string, fn: () -> ())
t.beforeEach(fn: () -> ())
t.expect(value: any)   -- returns matchers:
  .toBe(expected)                -- ==
  .toEqual(expected)             -- TableUtil.deepEqual
  .toBeCloseTo(expected, eps?)   -- |a-b| <= eps, default 1e-6
  .toBeNil()  .toBeTruthy()  .toBeFalsy()
  .toBeGreaterThan(n)  .toBeLessThan(n)
  .toContain(item)               -- list membership
  .toThrow()                     -- value is a function
  .never                         -- negates the next matcher

TestKit.run(root: Instance, filter: string?): {
  passed: number, failed: number,
  failures: { { name: string, message: string } },
}
-- Runs every descendant ModuleScript whose name ends in ".spec" and, when
-- filter is given, whose name contains filter. A spec that errors on require
-- counts as one failure. Test names are "describe > it".

-- RunUnit: return function(filter: string?) -> the TestKit.run result for
-- ServerScriptService.Tests.unit
```

**Tests** (`TestKit.spec.luau` tests TestKit with a nested private run):
- A passing `it` raises `passed` by 1.
- `expect(1).toBe(2)` gives 1 failure whose message contains `expected 2, got 1`.
- `expect({a={1}}).toEqual({a={1}})` passes; `.never.toEqual` fails.
- `beforeEach` runs before every `it` in its `describe` and in nested ones.
- `expect(function() error("x") end).toThrow()` passes.

**Tests** (utilities):
- Signal: two handlers both receive `Fire(1, 2)`; `Once` fires one time; after `Disconnect` the handler is not called; a handler that errors does not stop the next.
- Rng: two `Rng.new(42)` give the same 10 `int(1, 100)` values; `sample(list, 3)` returns 3 distinct items; `sample(list, #list + 1)` throws; `shuffle` keeps the same multiset.
- TableUtil: `deepEqual({1,{2}}, {1,{2}})` true; `deepEqual({1}, {1,2})` false.

- [ ] Follow the standard task cycle. Until F7 and F8, run the specs by pasting `return require(game.ServerScriptService.Tests.RunUnit)()` into the Studio command bar of a place built with `rojo build` (the user may need to do this once; ask).
- [ ] Commit: `feat: add TestKit and unit runner`.

### Task F7: Headless test runner and CI

**Needs:** H-2, H-3.

**Files:**
- Create: `tools/ci/cloud_test.py`, `.github/workflows/ci.yml`
- Modify: `docs/DECISIONS.md` (record the endpoints that worked)

**Behaviour of `cloud_test.py`** (Python 3.11, standard library only):
1. Read `ROBLOX_API_KEY`, `BLEAK_TEST_UNIVERSE_ID`, `BLEAK_TEST_PLACE_ID` from the environment. Exit code 2 with a clear message if one is missing.
2. Run `rojo build default.project.json -o build/test.rbxl`.
3. Publish `build/test.rbxl` to the test place as a **saved, not published** version and read the new version number. Use the request shape in https://create.roblox.com/docs/cloud/guides/usage-place-publishing. Confirm the shape on that page first.
4. Create a Luau Execution task **on that version** with script `return require(game.ServerScriptService.Tests.RunUnit)(<filter or nil>)` and `timeout` `"300s"`.
5. Poll every 2 s, up to 300 s, until state is `COMPLETE` or `FAILED`.
6. Print each failure as `FAIL <name>: <message>`, then `PASS <passed>/<total>` or `FAILED <failed>/<total>`.
7. Exit code 0 only when the state is `COMPLETE`, the returned table exists, and `failed == 0` and `passed > 0`. (A key without the scope can return success without running: `passed > 0` guards this.)
8. Argument: `--filter <text>`.

**`ci.yml`:** on push and pull request. Jobs: `lint` (ubuntu-latest; install Rokit with the `CompeyDev/setup-rokit` action, pinned to the latest release tag shown on its GitHub page, then run `tools/ci/lint.sh`) and `unit` (needs lint; runs `python tools/ci/cloud_test.py`; secrets `ROBLOX_API_KEY`; repository variables `BLEAK_TEST_UNIVERSE_ID`, `BLEAK_TEST_PLACE_ID`). Use a concurrency group `cloud-test` so runs do not exceed 5 task creations per minute.

- [ ] **Step 2:** Run `python tools/ci/cloud_test.py`. Expected: `PASS N/N`, exit code 0.
- [ ] **Step 3:** Break one spec on purpose (`expect(1).toBe(2)`), run again. Expected: a `FAIL` line, `FAILED 1/N`, exit code 1. Revert.
- [ ] **Step 4:** Unset `ROBLOX_API_KEY` in the shell, run. Expected: exit code 2.
- [ ] **Step 5:** Write `ci.yml`, push a branch, confirm both jobs pass.
